- [Amie](https://amie.so/) - A daily planner combining tasks, calendar, and email in one view. It is designed for individuals who want to plan their day with time blocking. Offers free and paid plans. ([Read more](/details/amie.md)) `Freemium` `Free Plan` `Calendar` `Time Blocking` `Daily Planner`
- [Motion](https://motion.com/) - An AI-powered calendar and task manager that automatically schedules tasks. It combines project management, meeting booking, and time blocking. - [Sunsama](https://sunsama.com/) - A daily planner and time-blocking tool that integrates with calendars and task services. Users organize tasks into daily workdays with guided planning. ## Open-Source & Self-Hosted

- [Kanboard](https://kanboard.org/) - An open-source Kanban project management software for small teams. It is self-hosted via PHP and supports task boards, subtasks, and user permissions. Source code is available under the MIT license. ([Read more](/details/kanboard.md)) `Open Source` `Self-Hosted` `Free` `Kanban` `PHP`
- [Super Productivity](https://super-productivity.com/) - An open-source task manager and time tracker with Jira, GitLab, and GitHub integration. It is designed for developers and runs as a desktop application. Source code is publicly available. ([Read more](/details/super-productivity.md)) `Open Source` `Free` `API` `Developer` `Time Tracking`
- [Taiga](https://taiga.io/) - An open-source project management platform for agile teams. It offers Kanban and Scrum boards, backlogs, and issue tracking. Can be used as a cloud service or self-hosted. ([Read more](/details/taiga.md)) `Open Source` `Self-Hosted` `Agile` `API` `Scrum`
- [Vikunja](https://vikunja.io/) - An open-source to-do list and task manager with self-hosting options. It supports lists, tasks, reminders, and sharing. Available as a hosted service or self-hosted Docker deployment. ([Read more](/details/vikunja.md)) `Open Source` `Self-Hosted` `Free Plan` `API` `Docker`
- [Wekan](https://wekan.github.io/) - An open-source Kanban board application for team task management. It supports cards, checklists, labels, and real-time updates. It can be self-hosted using Docker or Cloudron. ([Read more](/details/wekan.md)) `Open Source` `Self-Hosted` `Free` `Kanban` `Docker`

## Personal To-Do Apps

- [Remember The Milk](https://www.rememberthemilk.com/) - A task manager for busy individuals with smart lists, reminders, and offline access. It integrates with Gmail, Outlook, and other services. - [Things 3](https://culturedcode.com/things) - A task manager for Apple devices focusing on simplicity and GTD-style organization. It uses areas, projects, and checklists with a native macOS and iOS interface. Purchased as a one-time paid app per platform. - [TickTick](https://ticktick.com/) - A to-do list and task manager with built-in calendar, pomodoro timer, and habit tracking. It is available on web, desktop, and mobile. Offers free and premium subscriptions. ([Read more](/details/ticktick.md)) `Freemium` `Free Plan` `Calendar` `Habit Tracking` `Cross-Platform`
- [Todoist](https://todoist.com/) - A task manager for capturing and organizing to-dos across platforms. It supports projects, labels, filters, and collaboration.
